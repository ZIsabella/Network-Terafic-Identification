Repository Structure

.
├── DatasetGen_Step1_Fin.py      # Raw PCAP extraction (70-class)
├── DatasetGen_Step2_[App].py    # Binary split (Lantern/Skype)
├── [App]_Train.py               # SAE Pre-training & CNN Classification
├── [App]_PreProcess.py          # Inference preprocessing
├── [App]_SystemTest.py          # End-to-end evaluation
└── README.md
Key Parameters

Parameter	Value
Input	1480-byte (Truncated 1500-byte)
SAE Layers	[416, 320, 256, 192, 128, 64]
Classifier	1D-CNN (8/16 Filters)
Activation	ReLU
Training	Batch 1024, Dropout 0.2, L2 0.0005
Pipeline Execution
Dataset Generation:
bash
   python DatasetGen_Step1_Fin.py             # Create X_Data.npy / Y_Data.npy
   python DatasetGen_Step2_Lantern.py         # Create binary Lantern dataset
   
Training:
bash
   python Lantern_Train.py                    # Train SAE-CNN model
   
Inference (System Test):
bash
   python Lantern_PreProcess.py               # Process raw test PCAPs
   python Lantern_SystemTest.py               # Run inference
   
(Repeat same logic for Skype_* scripts)

Requirements
tensorflow (v1.x/v2.x compat)
dpkt, numpy, scikit-learn, matplotlib
Disclaimer
Scientific Basis: The code implements a hybrid SAE-CNN methodology similar to the accompanying research paper (“مقاله دوم.pdf”), which focuses on Zoom traffic.
Scope: This implementation applies the architecture specifically to Lantern VPN and Skype traffic identification. Numerical results (Accuracy, F1, etc.) depend on local dataset experiments and should be generated by the training scripts.
